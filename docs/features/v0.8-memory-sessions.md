# 三机制长记忆（v0.8）

v0.8 在上下文管理之上加三层：项目指令 / 长期记忆 / 会话存档。

## 三层项目指令

三层 `BaoZiCode.md` 按优先级拼接注入 `stable_system` 顶部（高优先级在前）：

```
~/.config/baozicode/BaoZiCode.md      # user_global（最低）
<项目>/.baozicode/BaoZiCode.md         # project_local
<项目>/BaoZiCode.md                    # project_root（最高）
```

- `@include <relpath>` 引用：深度 ≤ 5 / 环路拦截（`visited` 集合）/ 项目目录白名单
- 三层全无 → 静默 + banner 一行建议
- `LoadedInstructions = {layers, concatenated}`

## JSONL 会话存档

- 追加写 `sessions/<YYYYMMDD-HHMMSS-xxxx>.jsonl`（每条 message + flush + fsync，崩只丢最后一行）
- `session_id` 格式：`YYYYMMDD-HHMMSS-xxxx`（20 字符，4 字符随机 hex 防同秒撞车）；
  启动时自动迁移 v0.7 旧 uuid 目录，撞名挂 `_legacy` 后缀
- 续接四件套：坏行跳过 / orphan tool_call 截断 / token 超限自动压 / 间隔 > 8h 插 `time_gap` reminder
- 30 天过期 session 启动时自动清理
- CLI flag：`--resume <SESSION_ID>` / `--new` / `--no-banner`；无 flag + 有历史 → 弹 `StartupSessionScreen`

## 双层自动笔记

- 双层物理隔离：`user_dir`（跟人走）/ `project_dir`（跟项目走），各一份 `MEMORY.md` 索引
- 4 类笔记 + 自动路由：`user-pref` / `correction` → user；`project` / `reference` → project
- 索引 200 行 / 25KB 上限，灌进 system prompt 顶部 `## 长期记忆 (用户级)` / `## 长期记忆 (项目级)` 段
- Agent 自然停下后**异步**调 LLM 抽取笔记（快照式并发，去重交给 LLM 判断）
- 溢出状态机：`NORMAL → WARN → AUTO_COMPRESS（回 NORMAL）→ HUMAN_NEEDED`
- 跨 session 删除别人写的笔记被拒（防互踩）；`update` 允许跨 session 追加 / 合并

启动顺序：`permissions → instructions → memory → sessions`。

详细迁移见 [../migrations/v0.7-to-v0.8.md](../migrations/v0.7-to-v0.8.md)。
