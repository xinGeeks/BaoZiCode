# v1.1 → v1.2 迁移指南 — SubAgent Delegation

v1.2 是 v1.1 之后的大版本:主 Agent 获得**子任务委派**能力 — 通过统一的 `task`
工具把子任务派给独立的子 Agent,每个子 Agent 跑自己的对话上下文、用自己的工具集、
有自己的权限追踪。子 Agent 跑完结果**异步回流**主 Agent,主对话历史不再被污染。

**有 breaking change** — `SkillExecutor` 旧的 `independent_runner` 注入路径删除;
不写 Skill 或只用 shared 模式的项目零影响。

---

## 一、发生了什么变化

| 维度 | v1.1 | v1.2 |
|------|------|------|
| 子任务执行 | 全部 inline;主 Agent 跑 sub-tool 期间上下文被占满 | 主 Agent 调 `task` 工具派 sub-Agent,async 默认走后台 |
| 上下文隔离 | sub-tool 直接写主对话历史 | sub-Agent 跑独立 ConversationManager,跑完只回摘要 |
| 工具集 | sub-tool 继承父 Agent 的全部工具 | sub-Agent 走 4 层 AND filter(GLOBAL_DENY → role.tools → role.tools-deny → background_whitelist) |
| Fork 模式 cost | 不存在 | sub-Agent 共享 `parent._prompt` byte-identical,LLM prompt cache 命中 |
| 角色定义 | 无 | AgentDef frontmatter(description / tools / tools-deny / model / max-iterations / permission-mode / nesting-depth) |
| Skill 独立模式 | 走 `IndependentRunner` callback | 走 `SubAgentManager.dispatch(type="definition", ...)` |
| TUI 状态栏 | `[DEFAULT] idle` | `[DEFAULT] idle [agents: 0/0/0]` |
| TUI sub-Agent | 无 | `SubAgentCard` 折叠卡片 + 完成 toast |

## 二、新概念

### 2.1 AgentDef — 角色定义(frontmatter + body)

```markdown
<!-- ~/.config/baozicode/agents/explorer/AGENT.md -->
---
name: explorer
description: 只读探索仓库,产出一个简明摘要
tools: [Read, Grep, Glob, WebFetch]
model: sonnet
max-iterations: 8
permission-mode: permissive
---
你是一名只读探索 agent。输入一个目标(文件路径 / 关键字 / 问题),你需要:
1. 用 Read / Grep / Glob 在项目根下扫描
2. 调用 WebFetch 抓必要的外部文档
3. 用一段 ≤ 200 字的 Markdown 摘要回到主 Agent

禁止:任何写操作(Bash / Write / Edit)、任何 sub-Agent 嵌套(task 工具被硬禁)。
```

**加载优先级(同名覆盖)**:
1. `<project>/.baozicode/agents/` — 项目级
2. `~/.config/baozicode/agents/` — 用户级
3. `<pkg>/baozicode/agents/builtin/` — 内置(2 个样板:`explorer` / `summarizer`)
4. MCP plugin(server 暴露 `agents://list` 资源)

### 2.2 两条派发路径

```yaml
# definition 模式 — 跑独立角色(默认)
tool_input: {"type": "definition", "role": "explorer", "prompt": "扫 src/ 列出所有 .py 文件", "async": true}

# fork 模式 — 复用主 Agent 历史(命中 prompt cache,省钱)
tool_input: {"type": "fork", "prompt": "基于上面结果筛匹配 pattern X 的文件"}
```

- `async: true`(默认)→ 派完即返回 task_id,后台跑
- `async: false`→ 阻塞等完成(可设 `timeout_seconds`,超时自动切后台)
- `fork` 模式 `async: false` → **强制后台**(warning 日志 + 强制 async=True)

### 2.3 工具过滤 4 层 AND

```python
GLOBAL_DENY = frozenset({"task"})        # L1 — 禁嵌套(子 Agent 不能调 task)
role.tools: list[str] | None              # L2 — 角色白名单(None = 全允许)
role.tools_deny: list[str] | None        # L3 — 角色黑名单
background_whitelist: list[str]           # L4 — 后台模式额外白名单(默认 Read/Grep/Glob/WebFetch/notify_complete)
```

任一层过滤后为空 → `ToolFilterEmptyError`(dispatch 时被捕获并转成 `ToolResult(is_error=True)`)。

### 2.4 状态回流

| 主 Agent 状态 | 子 Agent 完成 | 回流方式 |
|--------------|--------------|---------|
| idle | 子 Agent done | 直接 `add_user("[explorer 子对话结果]\n...")` 进主对话,主 Agent 下条 user 消息自动触发 run |
| running | 子 Agent done | 走 `enqueue_reminder("subagent_result", ...)`,下轮顶部消费 |

## 三、Skills 独立模式 — Breaking Change

### 3.1 旧接口删除

```python
# v1.1 — 已删除
class SkillExecutor:
    def __init__(self, ..., *, independent_runner: Callable): ...

# v1.2 — 改用 SubAgentManager
class SkillExecutor:
    def __init__(self, ..., *, subagent_manager: SubAgentManager | None): ...
```

**影响**:
- 在 `BaoZiCodeApp` bootstrap 中手动构造 `SkillExecutor` 的项目 → 把 `independent_runner=runner` 改成 `subagent_manager=app.subagents`
- 旧 e2e 测试往 `executor._independent_runner = ...` 直接注入 → 改成模拟 `SubAgentManager.dispatch(...)`

`SkillExecutionResult.raw_output` 字段保留(完整 sub-Agent 输出),summary 改成
`f"[{name} 子对话摘要]\n{output}"` 格式。

### 3.2 不受影响

- shared 模式 Skill — 零变化
- 普通 `/skill <name>` 命令(shared 模式)— 零变化
- `/skill <name> [args]` 触发独立 Skill — 行为相同(用户视角),但后端走 SubAgent 通道
- `SkillExecutor` 业务逻辑 — `mode`, `args`, `summary` 全部保留

## 四、新配置块 — `subagents:`

```yaml
# config.yaml(v1.2 起可选)
subagents:
  enabled: true                # 默认 true;false → bootstrap 空集
  max_concurrent: 5            # 1-20,默认 5
  default_timeout_seconds: 300 # 10-3600,默认 5 分钟
  background_whitelist:        # 后台模式额外白名单
    - Read
    - Grep
    - Glob
    - WebFetch
    - notify_complete
  task_retention_minutes: 5    # 完成的 task 在 list_tasks() 留存多久
  plugins_enabled: true        # MCP plugin loader 开关
```

**不写 `subagents:` 块** → bootstrap 全用默认值(enabled=True)。

## 五、TUI 变化

### 5.1 状态栏

```
● [DEFAULT] · anthropic/claude-haiku-4-5 · ask · idle [agents: 0/0/0]
● [DEFAULT] · anthropic/claude-haiku-4-5 · ask · running · 3/20 · tool: Bash [agents: 2/0/0]
```

`[agents: R/D/F]` — R = running + pending,D = done + canceled,F = failed。

### 5.2 SubAgentCard 折叠卡片

- 折叠(默认):`◉ reviewer (definition · running) · 草稿内容预览…` 点击展开
- 展开:显示完整 last_text + task_id,再点击折叠
- 终态颜色:done/canceled/timeout 绿边;failed 红边
- 0.5s 自动轮询 `app.subagents.list_tasks()` 增量刷新

### 5.3 完成 toast

子 Agent 第一次进入 terminal 状态 → `App.notify("✓ [reviewer] 子对话完成", timeout=3)` 弹一次。

## 六、MCP Plugin — 新增能力

如果你的 MCP server 实现 `agents://list` + `agents://<name>` 资源协议,v1.2 启动时会自动
拉 AgentDef 注册到 SubAgentManager(同名按项目 > 用户 > 内置 > plugin 优先级)。

```python
# server 端契约(MCP resources/read)
async def read_resource(uri: str) -> dict:
    if uri == "agents://list":
        return {"contents": [{"text": json.dumps([
            {"name": "browser", "description": "浏览器自动化", "version": "1"},
        ])}]}
    if uri == "agents://browser":
        return {"contents": [{"text": """---
name: browser
description: 浏览器自动化
tools: [Bash, Read]
permission-mode: permissive
---
... body ...""")}]}
    raise ValueError("unknown uri")
```

**降级**:server 端任何异常 → 该 server 整个跳过;plugin agent 详情拉取失败 → 跳过该 agent,其他 agent 正常。

## 八、常见问题

**Q: fork 模式命中 cache 能省多少?**
A: Anthropic prompt cache 按 input token 计费约 1/10;sonnet 长对话 fork 通常省 60-80% input cost。
具体看 UsageStats: `/status` 命令看 `cache_read_tokens / (cache_read_tokens + input_tokens)`。

**Q: 子 Agent 能调 `task` 工具吗?**
A: 不能。`GLOBAL_DENY = {"task"}` 在 sub-Agent 工具过滤链路的最外层硬拦截,任何
permission-mode(包括 permissive)都拦。

**Q: 主 Agent 取消时子 Agent 会怎样?**
A: cascade cancel — `Agent.cancel()` 检测自己有 `_subagent_manager` 时调
`manager.cancel_all()`,所有 running 的 sub-Agent 5s 后 cancel_event 收到信号停掉。

**Q: 子 Agent 失败会怎样?**
A: 主 Agent idle → `add_user("[role 子对话失败]\n{error}")` 推回主对话作为下条 user 消息;
主 Agent running → `enqueue_reminder("subagent_result")` 下轮顶部消费。
TUI 弹红色 ✗ toast。

**Q: 没配 `subagents:` 块,默认全开吗?**
A: 是。`enabled: true` + `max_concurrent: 5` + `task_retention_minutes: 5`。要关掉整个系统
设 `enabled: false`,SubAgentManager 不构造、task 工具不注册。
